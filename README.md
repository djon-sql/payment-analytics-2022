# Payment Analytics 2022

Аналіз платіжних транзакцій за 2022 рік: якість даних, ключові KPI, динаміка Payment Success Rate, причини невдалих recurrent-платежів та вплив помилки `3.02` на користувачів.

## Мета проєкту

Дослідити платіжний домен за 2022 рік, виявити ключові тренди та проблемні зони, визначити основні причини невдалих платежів і сформувати практичні рекомендації для покращення платіжного процесу.

## Основні результати

- Проаналізовано **565 315** платіжних спроб від **115 245** унікальних користувачів.
- Загальний **Payment Success Rate — 44.47%**.
- Recurrent-платежі формували близько **75%** платіжного потоку та були головним драйвером погіршення загального Success Rate.
- Серед recurrent failures особливо виділялась помилка **`3.02`**.
- З помилкою `3.02` зіткнулися **25 987** унікальних користувачів.
- Після першої `3.02`: **42.20%** користувачів надалі мали хоча б один успішний recurrent-платіж, **53.35%** продовжували спроби без успішної оплати, **4.45%** більше не мали recurrent-спроб у межах доступних даних.

## Обмеження

- `bank_name` не проходив повну нормалізацію, тому один банк може бути представлений декількома варіантами назви.
- `additional_302` використовується як орієнтовна оцінка внеску, а не як доказ причинності.
- Наступний успішний платіж користувача не обов'язково є повторною спробою того самого `order_id`.
- Відсутність наступних recurrent-операцій у даних не означає churn користувача.
